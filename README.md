# Personal GitHub Pages Website

A simple responsive personal portfolio built with HTML, CSS, JavaScript, Bootstrap 5, and Bootstrap Icons.

## Files

- `index.html` - main website
- `assets/css/style.css` - custom styling
- `assets/js/main.js` - small UI interactions
- `assets/images/` - place profile/project images here

## Customize

Search `index.html` for:

- `Your Name`
- `your@email.com`
- `https://github.com/`
- `#` placeholder links

Replace them with your real information.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. For a personal site, name it `YOUR_USERNAME.github.io`.
3. Upload all files from this project.
4. Open repository Settings.
5. Open Pages.
6. Select your repository branch as the publishing source if required.
7. Your site will be available at `https://YOUR_USERNAME.github.io/`.

## Local testing

Open `index.html` directly in a browser, or use the VS Code Live Server extension.
